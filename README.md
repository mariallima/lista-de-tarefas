Parte Conceitual

1. o que é um commit?
R: o commit é um comando para criar um codigo-fonte 

2. qual é a finalidade de uma branch?
R: é uma linha de codigo, nao fazemos todas as alteracoes na branch principal para nao dar problema na branch principal

3. para que serve o .gitignore?
R: ele serve para ignorar arquivos que nao precisamos no github

4. qual é a diferença entre git e github?
R: o github é como se fosse uma rede social, que podemos colocar os codigos guardado, ja o git é usado para versionar  
 
5. o que aconteceu quando fizemos o merge?
R: ele juntou a branch principal e a segunda branch
